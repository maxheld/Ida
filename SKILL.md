# Skills

This repository includes the following skills (as listed in `AGENTS.md`):

- app-store-changelog: Create user-facing App Store release notes based on git history or tags.
- gh-issue-fix-flow: End-to-end GitHub issue fix flow using `gh`, local changes, tests, commit, and push.
- ios-debugger-agent: Build/run/debug the iOS app on a simulator via XcodeBuildMCP.
- macos-spm-app-packaging: Scaffold and package SwiftPM-based macOS apps outside Xcode.
- swift-concurrency: Guidance on Swift Concurrency best practices and patterns.
- swift-concurrency-expert: Review/remediate Swift Concurrency issues for Swift 6.2+.
- swiftui-liquid-glass: Implement/review iOS 26+ Liquid Glass UI in SwiftUI.
- swiftui-performance-audit: Audit and improve SwiftUI runtime performance.
- swiftui-ui-patterns: SwiftUI view/component patterns and examples.
- swiftui-view-refactor: Refactor SwiftUI views for structure and dependency injection.
