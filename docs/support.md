# Ida Support

Effective date: February 15, 2026

## Contact and Help

If you need help with Ida, please open a support issue on GitHub:

- https://github.com/maxheld/ida-app/issues

When reporting a problem, include:

- Device model
- iOS version
- Ida app version
- What you expected to happen
- What happened instead
- Reproduction steps

Please do not post private personal data (for example child names or personal health details) in public issues.

## What Ida Does

Ida currently supports:

- Logging child-related activity entries
- Local data storage on device
- Optional iCloud sync/share through Apple CloudKit
- Local notifications for reminders

## Common Troubleshooting

### iCloud sync is not updating

- Confirm iCloud Drive is enabled on the device.
- Confirm Ida has iCloud permission in iOS settings.
- Confirm you are signed into iCloud on all devices.
- Wait briefly after changes; CloudKit sync can be delayed.

### Reminders are not delivered

- Check notification permission for Ida in iOS Settings.
- Ensure Focus/Do Not Disturb is not suppressing alerts.
- Verify reminder time and repeat settings in the app.

### I can’t access shared logs

- Make sure the invite link was accepted on a device logged into iCloud.
- Confirm both users have network access and iCloud available.
- Retry opening the share link from the same Apple ID that accepted it.
